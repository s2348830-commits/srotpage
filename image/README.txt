【演出ファイルの配置方法】

演出は同じ番号のMP4ファイルを1G演出セットとして自動認識します。

■ フォルダ構成
  image/
  ├─ レバー/   ← レバーON演出
  │    ├─ 1.mp4
  │    ├─ 2.mp4
  │    └─ ...
  ├─ 1/        ← 第1停止演出
  │    ├─ 1.mp4
  │    ├─ 2.mp4
  │    └─ ...
  ├─ 2/        ← 第2停止演出
  │    ├─ 1.mp4
  │    ├─ 2.mp4
  │    └─ ...
  ├─ 3/        ← 第3停止演出
  │    ├─ 1.mp4
  │    ├─ 2.mp4
  │    └─ ...
  ├─ push.mp4  ← PUSH演出（当たり確定時のみ再生）
  ├─ reel/     ← リール図柄画像（任意）
  │    ├─ 赤7.png
  │    ├─ 青7.png
  │    ├─ BAR.png
  │    ├─ ベル.png
  │    ├─ リプレイ.png
  │    ├─ スイカ.png
  │    ├─ チェリー.png
  │    └─ ハズレ.png
  └─ title.png ← タイトル画像（任意）

■ 演出の自動追加
  同じ番号のMP4を4フォルダすべてに入れると自動認識されます。
  例: 1.mp4を4フォルダに追加 → 1番演出が追加
      2.mp4を4フォルダに追加 → 2番演出が追加

■ 黒背景の透明化
  全MP4はscreen合成（mix-blend-mode: screen）で再生します。
  黒(0,0,0)の部分が透明になります。

■ PUSH演出
  image/push.mp4 を配置してください。
  当たりが確定されているゲームでプッシュボタンが押された時に再生されます。
